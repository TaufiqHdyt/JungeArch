# Junge Architekt

A content-driven architecture portfolio built with Astro and TypeScript.

## Development

```sh
pnpm install
pnpm dev
```

Run `pnpm check` for Oxlint, Oxfmt, and Astro diagnostics, or `pnpm build` for
the complete production validation. Use `pnpm format` to apply Oxfmt. Project
content lives in `src/content/projects`, while reusable UI lives in
`src/components`.

Legacy `.html` URLs are generated by Astro redirect routes so existing links
continue to work without retaining the previous Bootstrap/jQuery site.

## Project structure

```text
.
├── public/                 # Static files copied without processing
├── src/
│   ├── assets/             # Images processed and optimized by Astro
│   ├── components/         # Reusable Astro components
│   ├── content/projects/   # Markdown project entries
│   ├── layouts/            # Shared page layouts
│   ├── lib/                # Framework-independent helpers
│   ├── pages/              # File-based routes (required by Astro)
│   ├── styles/             # Shared styles and design tokens
│   ├── content.config.ts   # Content collection schema
│   └── env.d.ts            # Astro environment types
├── astro.config.mjs        # Astro configuration
├── package.json            # Scripts and dependencies
└── tsconfig.json           # TypeScript configuration
```

Add route files only under `src/pages`. Put source images in `src/assets` when
Astro should optimize them, and use `public` only for assets that must be copied
to the final site unchanged.
